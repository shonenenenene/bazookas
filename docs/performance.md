# Производительность и общий список недопустимого

**Скорость — главный приоритет игры.** Она обязана идти гладко на слабых ПК: встроенная графика Intel, старые ноутбуки.
Фича, которая роняет FPS, переделывается или выкидывается.

## Требования к картинке

| Требование | Как сейчас | Где |
|---|---|---|
| Рендер в низком разрешении с растяжением на экран | высота кадра 480 px, `pixelRatio = 1`, без сглаживания | `CLIENT.renderHeight` |
| Draw calls на кадр | **4** (карта, игроки, частицы, базука в руках); `sky_surf` — **5–6** (+небо, +малая луна, когда в кадре) | HUD: `draw N` |
| Материалы | только `MeshBasicMaterial` или свой простой шейдер | — |
| Свет и тени | никаких динамических; свет запечён в цвета вершин | — |
| Все игроки | один `InstancedMesh` | `render/players.ts` |
| Все частицы (ракеты, следы, взрывы, ножи) | один `Points`, складываются по яркости — маленькие и тусклые | `render/particles.ts` |
| Дальность прорисовки | = туман карты (`fog_far`) | — |
| HUD | DOM — только при изменении, частые значения ~10 раз/с; без `blur`, `backdrop-filter` | `ui/hud.ts` |
| Размер сборки | ~185 КБ gzip (JS), почти всё — three.js; картинки лун ещё ~250 КБ | `npm run build` |

## PERF-01. Отладочная строка
**Где:** любая карта, левый верх HUD.

**Шаги:** поиграть минуту в самом нагруженном месте:
- взрывы рядом;
- дождь ножей;
- 10 игроков или все манекены в кадре;
- на `sky_surf` — луна в кадре.

**Ожидаемо:**
- `draw` не выше нормы из таблицы.
- `fps` держится на частоте монитора (или на 60 на слабом ПК).
- `worst` не скачет периодически: регулярные пики раз в несколько секунд — признак сборщика мусора.

**Цель:** стабильные 60 fps на встроенной графике Intel. Эталонного слабого ПК для замеров пока нет — замерять на самом
слабом доступном и записывать `fps / worst / draw` в баг-репорт.

> В режиме проверки без видеокарты (headless Chrome со SwiftShader) FPS ничего не значит — смотреть только `draw`.

## PERF-02. Нет микрофризов
**Шаги:** 2–3 минуты бхопа, стрельбы и рокет-джампов.

**Ожидаемо:** нет коротких подвисаний раз в несколько секунд.

**Разработчику:**
- в горячем цикле (тик физики, кадр) **не создавать объекты**: векторы-черновики живут на уровне модуля, функции
  `math.ts` пишут в `out`;
- события (взрыв, урон) создаются редко — там можно.

## PERF-03. Сеть не нагружает
**Ожидаемо:** команда клиента ~16 байт 60 раз/с; снимки 30 раз/с; запрос `/api/rooms` раз в 3 с, только пока открыта
вкладка online.

## Общий список недопустимого

### Игра и движение
- Разная физика при разной частоте кадров или мониторе.
- Застревание и проваливание сквозь геометрию.
- Поправки предсказания при обычном движении в сети (рывки, откаты).
- Автопрыжок от зажатого пробела; бонус бхопа за зажатый пробел.
- Бесконечный подъём по стене (больше 3 отскоков за полёт).
- Пад, срабатывающий от касания без прыжка.

### Бой
- Урон и смерти, посчитанные клиентом в сети.
- Урон взрывом сквозь стену; прямое попадание в себя.
- Обход перезарядки сменой базуки.
- Повторный выстрел вместо подрыва у Switchblade, пока снаряд летит.
- Разные урон и толчок в песочнице и в сети.

### Интерфейс
- Меню поверх игры или игра, реагирующая на клавиши в меню.
- Вход в игру от клика внутри окна меню (кроме кнопки PLAY).
- Ник, вставленный как HTML (только как текст).
- Пробел/Tab прокручивают страницу или уводят фокус.
- Удаление ссылки на исходники из подвала меню (требование AGPL).
- Русский текст шрифтами VT323 / UnifrakturMaguntia (в них нет кириллицы).

### Сеть и сервер
- Сервер падает от мусорных сообщений или от ухода игрока.
- Бесконечные переподключения при отказе «комната полна» / лимит.
- Доступ к файлам сервера через адрес (только `dist/`).
- Старый клиент играет с новым сервером другой версии протокола.
- `TRUST_PROXY` включён без прокси (подделка IP и обход лимитов).

### Скорость
- Новый draw call без необходимости (новые эффекты — в общие `Points` / `InstancedMesh`).
- `MeshStandardMaterial` / `MeshPhysicalMaterial`, динамический свет, тени.
- Большие яркие частицы друг на друге (overdraw).
- Создание объектов в тике или кадре.
- Тяжёлая постобработка, которую нельзя выключить.
- Новая зависимость без крайней необходимости.

### Код (для разработчика)
- `three`, DOM и браузерные API в `src/shared/` (его запускает и сервер).
- `Math.random`, время (`Date.now`, `performance.now`) в правилах игры (`src/shared/`).
- Новое поле движения только в `PlayerState`. Его нужно провести ещё через `copyPlayerState`, `writeSnapshot` /
  `readSnapshot` (`NetMe`) и `applyServerState` в `prediction.ts`. Иначе `npm test` покажет поправки в `net prediction`.
- Изменённые сетевые сообщения без увеличения `PROTOCOL_VERSION`.
- Новая зависимость в сборке без её лицензии в `public/THIRD_PARTY_LICENSES.txt`.
- Код Quake / GPL-проектов дословно (пишем своё по алгоритмам — иначе лицензия всей игры станет GPL).
- «Крутилки» (числа баланса и ощущения) прямо в логике, а не в конфигах.
- `npm test` не `ALL PASS` или `npm run build` с ошибками перед коммитом.
