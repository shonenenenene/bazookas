## Как читать проверку

Каждая проверка имеет номер (`MV-03`, `CB-12`…) — на него удобно ссылаться в баг-репорте.

- **Где** — карта и режим (песочница или сеть).
- **Шаги** — что сделать по порядку.
- **Ожидаемо** — что должно получиться. Цифры с «≈» — примерные (зависят от того, как именно нажал),
  без «≈» — точные.
- **Недопустимо** — что считается багом, даже если «в целом работает».
- **Автотест** — имя проверки в `npm test`, которая следит за этим без человека. Если её нет — только руками.

Баг-репорт: номер проверки, карта, режим (песочница / сеть, пинг из HUD), что делал, что увидел, что ждал.
Для багов картинки — строка `fps · worst · draw` из левого верхнего угла.

## Режимы запуска

| Режим | Как открыть | Что это |
|---|---|---|
| Песочница | `http://localhost:5173/` (или `?map=имя`) | Одиночная игра с манекенами. Сервер не нужен |
| Сеть | `npm run server` + `npm run dev`, в меню вкладка **online** | Комнаты, матч, другие игроки |
| Сеть с пингом | добавь в адрес `&lag=150` | Искусственная задержка 150 мс туда-обратно — проверять неткод на одном ПК |
| Два игрока на одном ПК | два окна браузера с одной ссылкой `?room=…` | Проверка всего сетевого |

Карты: `speedway` (по умолчанию), `sky_surf`, `test_arena`.

## Словарь

| Термин | Что значит |
|---|---|
| **u/s** | юнитов в секунду. Юнит — единица длины Quake (≈ 2.5 см). Игрок — 32×56 юнитов |
| **Тик** | один шаг физики. Их ровно 60 в секунду (`TICK_RATE`), 1 тик ≈ 16.7 мс |
| **Песочница** | игра без сервера: всё считает браузер |
| **Манекен (бот)** | мишень: стоит, бегает влево-вправо или распрыгивает. Двигается тем же кодом, что игрок |
| **Сплэш** | урон взрывной волной (не прямым попаданием) |
| **Хитбокс** | коробка игрока, по которой считаются попадания. Голова — верхние 18 юнитов |
| **Рокет-джамп** | выстрел себе под ноги, взрыв подбрасывает |
| **Банни-хоп (бхоп)** | прыжки сразу при приземлении — скорость не теряется на трение и растёт |
| **Стрейф** | движение вбок (A/D). Стрейф + поворот мышью в полёте разгоняет |
| **Серф** | скольжение вдоль крутого склона (круче 45°), держась клавишей в его сторону |
| **Снимок (snapshot)** | состояние мира, которое сервер шлёт игрокам 30 раз в секунду |
| **Предсказание** | своё движение клиент считает сам, не дожидаясь сервера, — поэтому управление без задержки при любом пинге |
| **Поправка (correction)** | сервер посчитал иначе, чем клиент предсказал, — клиент сдвигается. В норме при обычном движении её нет |
| **Интерполяция** | чужих игроков рисуем чуть в прошлом (0.1 с), плавно между снимками |
| **Draw call** | одна команда видеокарте «нарисуй это». Чем меньше, тем быстрее на слабом ПК |
| **Overdraw** | один пиксель перерисовывается много раз (например, много наложенных частиц) — тормозит слабые видеокарты |

## Проверки без рук

- `npm test` — около 70 автопроверок физики, боя, сети и карт. Должно заканчиваться `ALL PASS`.
  Запускать после любых изменений в `src/shared/` и `src/*/net/`.
- `npm run build` — проверка типов и сборка. Должно пройти без ошибок.
- Автотесты проверяют цифры точно (высоту прыжка, урон, тайминги). Руками проверяется **ощущение**,
  интерфейс, звук, картинка и то, что автотесты не видят (браузер, мышь, реальная сеть).
